# سراج (Seraj) — پلتفرم روشن‌سازی نیاز

وب‌اپلیکیشن MVP برای روشن‌سازی نیازِ افرادِ به‌دنبال خدمت (۵۰ نفر پایلوت) با گردش‌کار منتور‌محور، بدون انجام خودِ خدمت تخصصی.

- **بک‌اند:** Express + Prisma + PostgreSQL (Docker)
- **فرانت‌اند:** React + Vite + Tailwind (RTL، فونت Vazirmatn، تم تیره)
- **اجرا در محیط توسعه:** `docker compose -f docker-compose.base44.yml up -d --build`
  - فرانت روی پورت 3000، بک‌اند روی 4000، دیتابیس Postgres 16
  - مهاجرت و داده اولیه (seed) به‌صورت خودکار در راه‌اندازی بک‌اند اجرا می‌شود

## تست قانون پیش‌نویس AI (مهم)

هیچ پیش‌نویس AI بدون تأیید منتور به عضو نمایش داده نمی‌شود. تست سمت سرور:

```bash
docker compose -f docker-compose.base44.yml exec -T backend node tests/draft-rule.test.mjs
```

## معماری، هاست و سرویس‌های بیرونی (مطابق پروپوزال v3)

### این معماری کجا و چطور هاست می‌شود؟

- **کانتینرها (Docker/Compose):** همه اجزا (Express، Postgres، Vite/nginx) در کانتینر بسته‌بندی شده‌اند؛ روی هر سروری که Docker دارد (VPS ابری یا داخل ایران) با `docker compose up -d` اجرا می‌شود.
- **گزینه هاست داخل ایران:** VPS داخل ایران (پرت، آروان، لیکوود و…) — مزیت: دسترسی بدون فیلتر برای کاربران ایرانی و اتصال مستقیم به درگاه بانکی/پیامک داخلی. Postgres را می‌توان روی همان سرور یا سرویس مدیریت‌شده (مثل دیتابیس ابری آروان) نگه داشت.
- **گزینه هاست خارج از ایران:** VPS خارج (Hetzner, DigitalOcean و…) — ساده‌تر برای CDN و بک‌آپ، ولی کاربر داخل ایران ممکن است به‌دلیل تحریم/فیلترینگ به سرویس‌های خارجی (مثل OpenAI) از روی سرور دسترسی راحت نداشته باشد.
- **دامنه/SSL:** Nginx reverse-proxy جلوی کانتینر فرانت/بک با گواهی Let's Encrypt.
- **یادآوری MVP:** برای پایلوت ۵۰ نفره، یک VPS کوچک (۲ گیگ رم) کافی است؛ مقیاس‌پذیری بعدی نیازمند جدا کردن Postgres و افزودن صف کارها است.

### سرویس پیامک OTP چیست و از داخل ایران در دسترس است؟

- کد تأیید ۶ رقمی OTP باید از طریق **درگاه پیامک داخلی ایران** ارسال شود؛ گزینه‌های رایج: **کاوه‌نگار (Kavenegar)**، **فراپیامک (Farapayamak)**، **ملی‌پیامک**. این سرویس‌ها از داخل ایران کاملاً در دسترس‌اند و نیازی به تحریم‌شکن ندارند.
- در این کد، با تنظیم `SMS_API_KEY` (و در صورت نیاز `SMS_API_URL`) در متغیرهای محیطی، ارسال واقعی فعال می‌شود. بدون کلید، کد فقط برای محیط توسعه در پاسخ API نمایش داده می‌شود (`devCode`) و پیامک واقعی ارسال نمی‌شود.
- SMS_API_KEY از پنل سرویس‌دهنده پیامک (مثلاً کاوه‌نگار → «API Key») تهیه می‌شود.

### سرویس هوش مصنوعی چیست و از داخل ایران در دسترس است؟

- برای دو کار استفاده می‌شود: **تبدیل صدا به متن** (Whisper یا معادل) و **تولید پیش‌نویس سؤال/جمع‌بندی برای منتور**.
- تنظیمات: `AI_API_KEY` + `AI_API_URL` (هر سرویس سازگار با OpenAI) + `AI_MODEL` + `AI_TRANSCRIBE_URL` / `AI_TRANSCRIBE_MODEL`.
- **دسترسی از داخل ایران:** OpenAI و اکثر سرویس‌های معتبر خارجی از IP ایران مستقیماً در دسترس نیستند (تحریم/فیلترینگ). راه‌حل‌های عملی:
  1. **سرویس واسط داخلی** (مثلاً Abel، بهین‌اسپیس، یا پروکسی‌های ایرانی ارائه‌دهنده API سازگار با OpenAI) — بهترین گزینه؛ بدون تحریم‌شکن کار می‌کند.
  2. اگر سرور خارج از ایران است، فراخوانی مستقیم OpenAI از سرور معمولاً کار می‌کند.
  3. خودمیزبانی مدل (مثل Whisper روی همان سرور) برای تبدیل صدا به متن — بدون وابستگی خارجی.
- بدون کلید، هر دو قابلیت با پیام شفاف «سرویس تنظیم نشده» غیرفعال‌اند و خروجی ساختگی تولید نمی‌شود؛ عضو می‌تواند متن را خودش بنویسد و منتور بدون AI هم می‌تواند کار کند.

### متغیرهای محیطی

| متغیر | کاربرد |
|---|---|
| `JWT_SECRET` | امضای توکن‌ها (در تولید حتماً مقدار تصادفی قوی) |
| `DATABASE_URL` | اتصال Postgres |
| `SMS_API_KEY` | کلید درگاه پیامک OTP (اختیاری در توسعه) |
| `AI_API_KEY` / `AI_API_URL` / `AI_MODEL` | سرویس هوش مصنوعی (اختیاری در توسعه) |
| `AI_TRANSCRIBE_URL` / `AI_TRANSCRIBE_MODEL` | نقطه پایان تبدیل صدا به متن (پیش‌فرض Whisper) |

## نکات کلیدی منطق کسب‌وکار (v3)

- هدف جمع‌بندی: **۲۴ ساعت از تخصیص منتور** (`clarify_target_hours` در تنظیمات ادمین)؛ تأخیرها در `Assignment.delayHours` ثبت و در گزارش ادمین قابل پیگیری است.
- سقف بستن پرونده در صورت عدم پاسخ فرد: **۷۲ ساعت** (`case_expiry_hours` قابل تنظیم)؛ پس از آن پرونده فقط‌خواندنی می‌شود (CLOSED_EXPIRED). یک sweep دوره‌ای هر ۵ دقیقه پرونده‌های منقضی را می‌بندد.
- شاخص شفافیت ۵ بخشی: مسئله، نتیجه، قیود و هزینه، منابع و اطلاعات، قدم بعدی — تکمیل هر بخش فقط با تأیید منتور.
- برگه نهایی پس از تأیید دوطرفه (منتور + فرد) برای عضو قابل دانلود است.
- سهم مشارکت (پیش‌فرض ۱۵۰ هزار تومان) فعلاً به‌صورت دستی توسط ادمین ثبت/تأیید می‌شود؛ درگاه پرداخت ندارد.
- دسترسی به پرونده‌ها (VIEW_CASE/DOWNLOAD_BRIEF) در لاگ حسابرسی ثبت می‌شود.
